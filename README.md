## Ejecutar localmente

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Loyix19/CV.git
   ```

2. Entra a la carpeta del proyecto:

   ```bash
   cd CV
   ```

3. Abre `index.html` con Live Server o con un servidor local.

El sitio también puede publicarse directamente con GitHub Pages porque es un proyecto estático, sin servidor ni dependencias de instalación.
